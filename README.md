# ERP管理系统

一个基于React、Redux和Ant Design的企业资源规划(ERP)系统。

## 功能模块

- 采购管理
- 库存管理
- 订单管理
- 财务管理
- 用户管理

## 技术栈

- React 18
- Redux (with Redux Thunk)
- React Router v6
- Ant Design
- Ant Design Pro Layout

## 环境要求

- Node.js >= 14.x
- npm >= 6.x 或 yarn >= 1.x

## 安装依赖

```bash
npm install
```

或使用 yarn:

```bash
yarn install
```

## 启动开发服务器

```bash
npm start
```

或使用 yarn:

```bash
yarn start
```

默认情况下，应用将在 http://localhost:3000 上运行。

## 构建生产版本

```bash
npm run build
```

或使用 yarn:

```bash
yarn build
```
